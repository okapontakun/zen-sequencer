# 禅シーケンサー

水面をタップすると音の玉が浮かぶ、癒しの音楽おもちゃ。ブラウザですぐ遊べます。

https://okapontakun.github.io/zen-sequencer/

## ファイル

- `index.html` … アプリ本体（この1ファイルで動きます）
- `og.jpg` … SNSでリンクを貼ったときのカード画像
- `favicon.ico` / `favicon-16.png` / `favicon-32.png` … ブラウザのタブのアイコン
- `apple-touch-icon.png` … iPhoneのホーム画面に追加したときのアイコン
- `icon-512.png` … 大きいサイズのアイコン
- `.nojekyll` … GitHub Pages でファイルをそのまま公開するための空ファイル
